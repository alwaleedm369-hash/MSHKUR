# استخدام REA في تطوير مشكور

REA (Reverse Engineer Anything) أداة MCP للتحليل العكسي. ليست خدمة تشغيل لمستخدم مشكور ولا تُضاف إلى خادم الإنتاج.

## المتطلبات المنشورة

تحقق من README الرسمي قبل التثبيت. المتطلبات المنشورة حالياً:
- Node.js 22.23.4+ أو 24.22.1+ أو 26.12.1+.
- npm.
- بعض التحليلات الأصلية تحتاج Hopper أو Ghidra أو IDA أو Kuna؛ تحليل JavaScript/Electron الثابت لا يحتاج محركاً أصلياً.

## الإعداد الاختياري

```bash
npx rea-agents setup
```

اختر بيئة الوكيل المناسبة، راجع التغييرات، وافق فقط على إعدادات MCP التي تحتاجها، ثم أعد تشغيل الوكيل. لا تنفذ هذا الأمر على حسابات/أجهزة غير مصرح بها.

## سير عمل REA داخل مشكور

1. اختر مشروعاً مفتوح المصدر أو تطبيقاً يملك الفريق حق فحصه.
2. حدد المهمة أو الرحلة المراد فهمها.
3. اطلب من REA الأدلة، نقاط الدخول، المدخلات، المخرجات، حالات الفشل، والاعتماديات.
4. سجل النتائج في ADR أو Skill spec مع الروابط والإصدارات والتراخيص.
5. نفذ MSHKUR نسخة مستقلة واكتب اختبارات سلوك.
6. لا تنقل الشيفرة أو الأصول أو العلامة التجارية إلا وفق الترخيص والحقوق.
