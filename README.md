# مشكور | MSHKUR OS

منصة تشغيل للمعارض تبدأ بإنجاز المهمة: إدارة السيارة، تجهيز الوسائط، إعداد الإعلان، ثم النشر بعد موافقة صاحب الصلاحية.

## الحالة الحالية

هذا المستودع يمر بمرحلة إعادة تأسيس موثقة. فرع `build/phase-01-real-foundation` يضيف أساس React/Express قابل للتشغيل، واجهة عربية RTL متجاوبة، ونقاط فحص API واختبارات أولية. لا تخلط بين هذه المرحلة وبين إطلاق منتج إنتاجي.

راجع:
- [تقرير التدقيق الأول](docs/PHASE_01_AUDIT_AR.md)
- [البنية وقرارات التقنية](docs/ARCHITECTURE_AR.md)
- [خارطة التنفيذ](docs/ROADMAP_AR.md)
- [ربط Google AI Studio وFirebase](docs/AI_STUDIO_IMPORT_AR.md)

## التشغيل

المتطلبات: Node.js 22 أو أحدث.

```bash
npm install
npm run dev
```

- واجهة Vite: http://localhost:3000
- API: http://localhost:4174/api/health

## الاختبارات والبناء

```bash
npm test
npm run typecheck
npm run build
npm run check
```

## ما يعمل في المرحلة الأولى

- واجهة React عربية RTL، متجاوبة للجوال وسطح المكتب.
- خادم Express مع `/api/health` و`/api/readiness`.
- رؤوس حماية أساسية وحد JSON للطلبات.
- تشغيل الواجهة والخادم في وضع التطوير.
- اختبارات API أولية.

## ما لم يُفعّل بعد

لا يوجد حالياً تسجيل Google أو Firebase Auth/Firestore أو قاعدة بيانات دائمة أو عزل معارض أو رفع صور دائم أو WhatsApp أو MCP أو نشر خارجي. بطاقات الواجهة الحالية لا تمثل تكاملات فعلية. هذه العناصر موضحة كمهام مستقلة في خارطة التنفيذ.

## سياسة التطوير

- لا أسرار في Git أو المتصفح.
- لا API مدفوع في المسار الأساسي دون موافقة مستقلة.
- لا تنفذ أوامر أو مهارات عشوائية صادرة من نموذج؛ المهارات تسجل بقائمة مسموحة ومخططات typed.
- لا تخترع بيانات السيارات ولا تغير هوية السيارة.
- لا إرسال أو نشر أو حذف دون موافقة صريحة على المحتوى والوجهة.
- REA أدوات بحث تطويرية منفصلة ولا تُضمّن في خادم المنتج.
- لا يُعلن عن تكامل إلا بعد handshake واختبار فعلي.
