# MSHKUR — Vehicle Photo Studio

**استوديو صور سيارات يعمل محلياً في المتصفح.** واجهة إنجليزية مع دعم العربية واتجاه RTL.

## معاينة المشروع

https://alwaleedm369-hash.github.io/MSHKUR/

## التجربة الحالية

- استيراد صور السيارات من الجهاز.
- إزالة الخلفية داخل المتصفح عبر `@bg0/browser` كاعتماد طرف ثالث.
- معاينة النتيجة ومقارنتها بالأصل.
- إخراج بخلفية بيضاء أو شفافة وتنزيل النسخة الناتجة.
- حفظ محلي في المتصفح حيث تدعم البيئة ذلك.
- واجهة عربية/إنجليزية.

## حالة المنتج

النسخة الحالية **نموذج أولي قابل للمعاينة** وليست إصداراً تجارياً نهائياً. مراجعة المالك للنسخة الأولى بتاريخ 27 نوفمبر 2026 حددت أولوية إعادة تنظيم الجوال، حذف الشعار والاسم من الترويسة، تخفيف النصوص، وتحسين العرض البصري بإضافة أمثلة قبل/بعد وGIF أو فيديو توضيحي.

راجع [مراجعة النسخة الأولى وخطة رفع الجودة](docs/PRODUCT_REVIEW_AND_DOCUMENTATION_UPDATE_AR.md).

## المعالجة والخصوصية

تتم إزالة الخلفية في المتصفح باستخدام مكتبة طرف ثالث؛ وقد يحتاج أول تشغيل إلى تنزيل أصول النموذج. الأداء والنتيجة يعتمدان على الجهاز والمتصفح والذاكرة. الصور الأصلية منفصلة عن النسخ الناتجة. التخزين المحلي ليس نسخاً احتياطياً سحابياً، وقد يتأثر بمسح بيانات الموقع أو وضع التصفح الخاص.

لا ندّعي وجود نموذج segmentation مدرّب داخلياً، ولا يوجد تكامل مع Higgsfield أو Blender أو WhatsApp API في هذه النسخة.

## التطوير والتحقق

المتطلبات: Node.js 22+ وnpm.

```bash
npm ci
npm run dev
npm test
npm run typecheck
npm run build
```

في آخر تحقق موثق لهذه النسخة: 87 اختباراً ناجحاً، ونجاح فحص TypeScript وبناء Vite، ونجاح GitHub Pages deployment. هذا لا يغني عن اختبار بصري وتفاعلي على أجهزة حقيقية.
