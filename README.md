# مشكور | MSHKUR OS — Research & Expansion Pack v1.1

حزمة تطوير وتوسعة مبنية على نواة MSHKUR OS السابقة ووثيقة المشروع. تركيز التأسيس الحالي هو **MSHKUR Cars**: المعارض والمخزون والوسائط والإعلانات وصفحات العرض واستفسارات العملاء. فحص السيارات مؤجل.

## التشغيل المحلي

```bash
npm install
npm run dev
```

لا يلزم مفتاح Gemini للوظائف المحلية الأساسية. أي مفتاح AI يوضع في أسرار الخادم فقط.

## الفحص والاختبارات

```bash
npm test
npm run typecheck
npm run build
```

## الموجود في الحزمة

- واجهة React RTL وخادم Express ومساحة مالك واحدة بتخزين JSON محلي.
- سجلات سيارات/عملاء ومهام وموافقات وصفحات عامة محلية، ومسودة إعلان من بيانات موجودة فقط.
- استوديو صورة محلي أساسي مع BG0 لإزالة الخلفية، مع حدود توافق الجهاز.
- أدوار مختصين ومهارات typed وخطط workflows.
- ثلاث مهارات بحث جديدة: تفكيك المنتجات بالأدلة، بحث المنافسين، تدقيق مشاريع GitHub/التراخيص.
- مهارات تصميمية جديدة لدورة بيع المعرض وبوابة MCP، وملفات أدوار Sales/Maps/Publisher/WhatsApp Lead.
- Playbook REA/AssetRipper يشرح حدود الاستخدام والتراخيص.
- وثائق AI Studio وHostinger والتدقيق الحالي لمستودع GitHub.

## ما يعمل فعلاً في هذه النسخة

تشغيل محلي، عدد من مسارات API المحلية، مهام ومشاريع وسيارات وعملاء وموافقات، صفحة عامة لسيارة منشورة محلياً، QR محلي، مسودة إعلان ثابتة، معالجة صورة محلية أساسية، واختبارات Node.

## ما ليس اتصالاً إنتاجياً بعد

لا يوجد تعدد مستأجرين أو قاعدة بيانات إنتاجية، ولا Google OAuth/Drive/Sheets، ولا واتساب متصل، ولا MCP server متصل، ولا نشر اجتماعي مباشر، ولا WebAR/3D حقيقي، ولا فحص سيارة/تشخيص أضرار، ولا استوديو فيديو متكامل. بطاقات التكامل والمهارات المخططة ليست دليلاً على تنفيذها.

## دمجها مع مشروع AI Studio العامل

هذه الحزمة **ليست snapshot مطابقاً لمشروع Build الحالي**. فحص مستودع GitHub `alwaleedm369-hash/MSHKUR` على `main` أظهر هيكل Starter صغيراً فقط. استخدم `docs/IMPORT_CURRENT_REPO_AR.md` و`docs/AI_STUDIO_SETUP_AR.md`: صدّر أولاً ZIP من مشروع AI Studio العامل، اربط المستودع والفرع، ثم اطلب الدمج مع الحفاظ على الكود والشاشات العاملة. لا تستبدل المشروع الحالي مباشرة.

## النشر

راجع `docs/HOSTINGER_DEPLOY_AR.md` و`docs/PDPL_CHECKLIST_AR.md`. واجهة static لا تشغل API أو التخزين أو CRM. تشغيل Express يتطلب خطة Node.js مناسبة أو خدمة Backend منفصلة، وتخزين JSON الحالي غير مناسب لخدمة عدة معارض.
