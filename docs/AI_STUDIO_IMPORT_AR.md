# ربط مشكور مع Google AI Studio وFirebase

## استيراد المستودع

1. افتح Google AI Studio ثم Build mode.
2. من قائمة إضافة الملفات اختر Import from GitHub.
3. استورد المستودع الخاص MSHKUR بعد منح AI Studio صلاحية الوصول المطلوبة.
4. راجع الملفات المستوردة قبل السماح بأي إعادة كتابة.
5. اربط المستودع من Settings > GitHub عند الحاجة للمزامنة ثنائية الاتجاه.
6. استخدم فرع التطوير build/phase-01-real-foundation للمراجعة، ولا تدمج إلى main قبل اجتياز الاختبارات ومراجعة التغييرات.

## إضافة Firebase

1. من AI Studio اطلب إضافة Firebase Authentication وCloud Firestore أو استخدم Settings > Integrations.
2. اختر Google Cloud project والمنطقة بعد مراجعة مكان تخزين البيانات؛ موقع قاعدة البيانات لا يمكن تغييره ببساطة بعد إنشائها.
3. فعّل Google Sign-In من Firebase Console > Authentication > Sign-in method.
4. أضف نطاقات التطوير والإنتاج المصرح بها.
5. راجع firestore.rules واختبرها باستخدام Firebase Emulator قبل بيانات حقيقية.
6. لا تجعل قواعد Firestore تسمح بالقراءة/الكتابة العامة.
7. لا تضع service-account JSON أو مفاتيح خادم في Git أو متغيرات VITE.
8. اختبر تسجيل الدخول، تسجيل الخروج، استعادة الجلسة، المستخدم غير المصرح، وفصل بيانات معرضين مختلفين.

## ملاحظات التكلفة

Firebase Auth يقدم خيارات مجانية ضمن حدود الخطة، بينما تختلف حدود Firestore وStorage وخدمات Google حسب المنتج والمنطقة والاستخدام. لا تفعّل موارد مدفوعة أو ترقية خطة دون مراجعة الميزانية والحدود. لا يحتاج المسار الأساسي إلى Gemini API مدفوع؛ لا نضيف استدعاءات نموذج إلى وظائف المخزون والصور المحلية إلا إذا أثبتت الحاجة.

## الوضع الحالي

هذه الوثيقة إرشادية. لا يوجد في فرع المرحلة الأولى حتى الآن Firebase project ID أو OAuth client أو handshake مع Google؛ لذلك تسجيل الدخول غير مفعل بعد.
