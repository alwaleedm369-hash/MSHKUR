# ملاحظة أرشيفية

هذه الوثيقة لم تعد جزءاً من مسار التنفيذ. Google AI Studio ليس بيئة التصميم أو التطوير أو التشغيل لمشروع MSHKUR.

المسار الحالي مستقل: GitHub للمصدر، React/TypeScript للواجهة، Node.js للخادم، SQLite للبيانات الأولية، ومهارات محلية. راجع [README](../README.md) و[خدمات Google الاختيارية](GOOGLE_SERVICES_AR.md).

Google OAuth والخرائط يمكن ربطهما مباشرة كموصلين مستقلين، ولا يتطلب ذلك Google AI Studio.
