# حالة التكامل الموحد — MSHKUR

آخر تحديث: 2026-11-19

## أساس الدمج

مرشح الإصدار `build/unified-release-mainline` مبني مباشرة على رأس `main`، وليس على فرع المرحلة الثانية أو على تاريخ متفرع متعارض. تمت مقارنة `main` مع خط تحسين الجوال والتصدير، ثم نقل التغييرات الخاصة بالواجهة والتصدير فقط إلى هذا المرشح، مع إبقاء بقية المحرك والميزات الموجودة في `main`.

## التغييرات المضافة إلى main

1. `src/App.tsx`: تحميل تحسينات الجوال، وجعل استوديو الصور نقطة الدخول الافتراضية بعد تسجيل الدخول. تظل لوحة الرئيسية متاحة من شريط التنقل.
2. `src/GuestStudio.tsx`: استخدام محرك العلامة المائية عند التصدير، مع إبقاء الصورة الأصلية ومسار المعالجة منفصلين.
3. `src/mshkurWatermark.ts`: محرك تصدير علامة مائية مستقل وغير هدّام، يقبل إعدادات مثل النص والشعار والشفافية والحجم والموضع.
4. `src/mobile-polish.css`: تحسينات عرض الواجهة على الشاشات الصغيرة.
5. `README.md`: توثيق أساس النسخة وخط التكامل.

## ما يحتفظ به المرشح من main

كل وحدات المشروع الموجودة على `main` قبل الدمج، بما فيها الواجهة العربية، محرك الصور، استوديو المشاهد، سجل الأصول والمقارنة، أدوات الإعلان، المهام والموافقات، إدارة المعرض، التخزين وقاعدة البيانات، والاختبارات.

## حدود ما تم التحقق منه

- تمت كتابة التعديلات على فرع مستقل؛ لم يُعدّل `main` مباشرة.
- لا يوجد حتى الآن دليل ناجح من GitHub Actions: تشغيلات التحقق والتغليف التي ظهرت في سجل المستودع انتهت بـ `startup_failure` قبل إظهار نتيجة الاختبارات.
- لم يتم تشغيل `npm test` أو `npm run build` محلياً في هذه الجلسة؛ لذلك لا نصف المرشح بأنه مختبر أو جاهز للإنتاج.
- الموصلات غير المنفذة تبقى غير مفعّلة، بما فيها WhatsApp Business API وGoogle OAuth/Drive/Gemini والكشف الآلي عن اللوحات والزجاج.

## بوابة الاعتماد

قبل الدمج إلى `main` أو إنشاء ZIP إطلاق:
- `npm ci` أو `npm install` على Node.js 22.
- `npm test`.
- `npm run typecheck` و`npm run build`.
- `npm run db:check` واختبار النسخ الاحتياطي والاستعادة على قاعدة اختبار.
- اختبار تدفق الصور من الرفع حتى إزالة الخلفية والمشهد والطمس والقص والمقارنة والتنزيل.
- اختبار العلامة المائية: ملف مصدّر بعلامة، وملف نظيف عند تعطيلها، دون تعديل الأصل.
- اختبار الجوال وسجل الأصول وعزل بيانات المعارض وموافقات النشر.
