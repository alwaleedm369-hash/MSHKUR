# مواصفات محرك صور السيارات والإعلانات — MSHKUR Cars

> وثيقة تنفيذية ملزمة للمرحلة التالية. الحالة: مواصفات وتصميم، وليست ادعاء اكتمال أو اختبار.

## 1. المنتج الذي نبنيه

مسار واحد واضح يبدأ من سيارة وصورها وينتهي بحزمة إعلان قابلة للمراجعة:

1. اختيار سيارة أو إنشاء سجلها.
2. إضافة صور متعددة مع حفظ الأصل دون تعديل.
3. ترتيب الصور واختيار صورة الغلاف.
4. تجهيز الصورة: قص/استقامة، إزالة الخلفية، طمس اللوحة، تحسين الإضاءة والألوان، إعداد خلفية المعرض.
5. معاينة قبل/بعد مع إمكانية الرجوع.
6. اختيار قالب معرض أو قالب منصة.
7. تجهيز صور بأحجام وصيغ مناسبة.
8. إنشاء عنوان ووصف ومواصفات من حقائق سجل السيارة فقط.
9. مراجعة النواقص والتعارضات.
10. تنزيل حزمة الإعلان أو حفظها في صفحة السيارة.
11. النشر خطوة منفصلة تتطلب موافقة المالك.

## 2. مبادئ تجربة المستخدم

- واجهة task-first: افتح المهمة مباشرة، لا لوحة تحكم مزدحمة.
- الهاتف أولاً، RTL عربي، مع دعم لوحة المفاتيح والشاشات الكبيرة.
- كل أداة تعرض النتيجة على الصورة نفسها؛ لا تنقل المستخدم بين صفحات غير ضرورية.
- الأصل محفوظ دائماً، وكل تعديل ينتج نسخة مشتقة.
- Undo/redo وسجل تعديلات غير هدّام قبل إضافة أدوات تحرير متقدمة.
- لا تُخفى العمليات الثقيلة: اعرض التقدم، الوقت التقريبي إن توفر قياس، وإمكانية الإلغاء الآمن.
- وضّح محلياً/خادمياً بجوار كل عملية. إزالة الخلفية الحالية محلية في المتصفح؛ تحسين WebP الحالي يتم عبر مهمة خادمية.
- لا ترفع صورة لمزود خارجي ولا تستخدمها للتدريب.

## 3. وحدات المحرك وترتيب البناء

### C1 — مكتبة الصور والألبوم
- صور متعددة لكل سيارة، مع أدوار: أصل، مشتق، غلاف، صورة داخلية/خارجية/تفصيل.
- ترتيب يدوي، حذف منطقي، اختيار الغلاف، وبيانات أبعاد/صيغة/حجم وبصمة.
- منع الكتابة فوق الأصل، وفحص MIME من التوقيع لا الامتداد فقط.
- قيود حجم وعدد وrate limit مع رسائل عربية مفهومة.

### C2 — محرر الصورة غير الهدّام
- عرض الأصل والنتيجة ومقارنة before/after.
- قص ونسبة أبعاد واستقامة وتدوير.
- طمس لوحة يدوي قابل للتعديل، مع عدم الادعاء بالكشف الآلي.
- Undo/redo وسجل عمليات قابل لإعادة التطبيق.
- التصدير إلى PNG/WebP/JPEG مع ملف مشتق جديد.

### C3 — إزالة الخلفية
- تنفيذ محلي داخل المتصفح افتراضياً.
- fallback واضح عند غياب WebGPU أو نقص الذاكرة، وعدم تعليق الصفحة.
- إلغاء عند نقاط آمنة، progress، cache للنموذج مع تثبيت revision وSHA-256.
- فحص الحواف والهالات والظلال تحت السيارة؛ لا نعد بجودة احترافية قبل benchmark لصور سيارات متنوعة.
- كل نموذج/وزن/ملف ONNX له سجل ترخيص مستقل قبل التوزيع.

### C4 — تجهيز استوديو السيارة
- قوالب خلفية محايدة ومتوافقة مع هوية المعرض.
- الحفاظ على شكل السيارة وألوانها وعدم توليد أجزاء غير موجودة.
- الظلال/الانعكاسات/تظليل الزجاج وظائف لاحقة؛ لا تستخدم generative fill قبل سياسة واضحة تمنع تغيير الحقائق المرئية للسيارة.
- كل قالب يحدد أبعاد التصدير والخلفية والهوامش.

### C5 — التحسين والتصدير
- WebP/JPEG quality presets، resize، metadata policy، وقياس حجم الملف.
- عدم رفع دقة الصورة بالـupscaling افتراضياً؛ لا نضيفه إلا بعد مراجعة النموذج وترخيص الأوزان وقياس أثره.
- ZIP متعدد الصور لاحقاً بعد اختبار الذاكرة والتدفق.
- الدفعات: تقدم لكل عنصر، إيقاف آمن، إعادة محاولة المتعثر فقط، واستعادة بعد تعطل الخادم قبل اعتبارها جاهزة إنتاجياً.

### C6 — منشئ الإعلان
- البيانات الموثقة من سجل السيارة هي المصدر الوحيد للمواصفات والسعر والعداد.
- لا تخمين سنة/فئة/مواصفات أو إضافة وعود تسويقية غير مؤكدة.
- قوالب عربية قابلة للتحرير: مختصر، تفصيلي، منصة، وصف صفحة السيارة.
- تقرير نواقص وتعارضات، وإظهار الحقول التي بني منها النص.
- حفظ نسخ الإعلان وإصداراتها، والنشر لا يحدث تلقائياً.

### C7 — صفحة السيارة والمعرض
- صفحة سيارة عامة سريعة، صور مرتبة، مواصفات مؤكدة، رابط مشاركة وQR.
- صفحات المعرض تعرض المنشور فقط، وبيانات التواصل بموافقة المالك.
- تحسين SEO والبيانات المنظمة بعد مراجعة الخصوصية وحقول العرض.

## 4. نموذج البيانات المقترح

- Vehicle: حقائق السيارة ومصدر كل حقل.
- VehicleAsset: original/derived، الدور، MIME، الحجم، الأبعاد، checksum، parent_asset_id.
- ImageOperation: نوع العملية، parameters version، input/output asset، الحالة، المدة، error code.
- ImagePreset: إعدادات مقاسات وخلفيات المعرض.
- AdDraft: نسخة النص، القالب، source_fields، validation report، status.
- ModelArtifact: اسم النموذج، upstream، revision، checksum، model license، code license، notices، commercial approval.
- LicenseEvidence: مصدر الدليل، تاريخ الفحص، commit/revision، reviewer، القرار.

لا تحفظ بايتات الصور في SQLite. قاعدة البيانات تحتفظ بالبيانات الوصفية، والملفات في تخزين دائم مع عزل tenant.

## 5. عقود الأدوات

كل أداة تعرف:
- input schema مضبوطاً وحجماً أقصى.
- output schema وإصداراً ثابتاً.
- مكان التنفيذ: browser أو server-local أو external connector.
- الصلاحيات والبيانات التي تقرؤها/تكتبها.
- حدود CPU/RAM/وقت وحجم الملفات.
- progress/cancel/retry semantics.
- error codes عربية مفهومة.
- fixture tests وgolden outputs.
- سجل provenance للمكتبات والأوزان.

## 6. بوابة الجودة والقبول

لا تعتمد أي أداة قبل:
1. عينة اختبار مرخصة أو صور اصطناعية لا تنتهك الخصوصية.
2. مجموعة سيارات متنوعة: ألوان داكنة/فاتحة، زجاج عاكس، عجلات وأسلاك، خلفيات مزدحمة، إضاءة ليلية ونهارية.
3. مقارنة بصرية عند 100% للحواف واللوحة والزجاج.
4. اختبار الهاتف المتوسط والكمبيوتر، مع وبدون WebGPU.
5. اختبار فشل/إلغاء/إعادة محاولة/انقطاع الشبكة/نفاد الذاكرة.
6. قياس زمن التنفيذ، حجم تنزيل النموذج، RAM، وحجم الملف النهائي.
7. تدقيق tenant isolation وMIME وpath handling وrate limits.
8. إكمال سجل تراخيص الكود والاعتماديات والأوزان والملفات الموزعة.
9. موافقة المنتج والأمن قبل تفعيل الميزة.

## 7. الموجود فعلياً وفق مراجعة الفرع

- إزالة خلفية محلية باستخدام `@bg0/browser` مع نموذج Lite.
- طمس منطقة يحددها المستخدم يدوياً.
- تحسين WebP عبر skill خادمية.
- ألبوم متعدد الصور لكل سيارة.
- حفظ نتائج إزالة الخلفية المحلية والتحسين والطمس ومشهد الاستوديو كأصول مشتقة، مع ربطها بملف الأصل عند اختيار صورة من الألبوم.
- تركيب مشهد محلي بخلفيات فضية/بيضاء/داكنة/دافئة، وظل وانعكاس تركيبيين على Canvas؛ لا يدّعي توليد انعكاس فيزيائي أو تعديل أجزاء السيارة.
- أداة تضليل زجاج يدوية بتحديد مضلع على الصورة واختيار لون/قوة التظليل؛ نافذة واحدة في كل تمريرة، دون اكتشاف تلقائي.
- دفعات تحسين متسلسلة مع إيقاف وإعادة محاولة مضافة.
- مسودة إعلان من بيانات السيارة والتحقق من النواقص.
- صفحة معرض عامة ونشر/إخفاء يدوي.

هذه الوظائف موجودة في الكود، لكن لا يعني ذلك اجتياز اختبارات قبول أو جاهزيتها للإنتاج. كشف اللوحة الآلي، تظليل الزجاج، الظلال الواقعية، محرر undo/redo، حزمة ZIP، ونشر المنصات الخارجية ليست مكتملة.

## 8. قرارات ممنوعة حالياً

- لا استيراد أو تشغيل مشروع خارجي داخل خادم مشكور.
- لا إضافة وزن نموذج قبل إثبات ترخيصه التجاري وحقوق إعادة التوزيع.
- لا صور سيارات مولدة أو تغييرات قد تحرف حالة السيارة الفعلية.
- لا إرسال صور إلى خدمة سحابية افتراضياً.
- لا ادعاء أن الأداة «تكتشف» أو «تصلح» تلقائياً ما لم يثبت ذلك بالاختبار.
- لا نشر إعلان أو مراسلة عميل دون موافقة بشرية صريحة.
