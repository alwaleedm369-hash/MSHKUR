# Execution sequence and gates

## Gate 0 — Baseline / repair
Audit repository, record Git status, identify syntax/type/dependency issues, clean install, baseline build/test/lint and evidence. Do not reorganize wholesale.

## Gate 1 — Shell UX
Mobile menu-only top edge; central 3-star AI entry in bottom navigation; compact language control (`E`); light-first sun/moon; app navigation; responsive, accessible shell. Test on viewport sizes and real devices when possible.

## Gate 2 — First real skill: removebackground
Select an open and licence-verified model/implementation; build reproducible local pipeline; preserve source; output transparent PNG; define mask refinement and failure handling; run benchmark set and visual QA. Do not substitute stock/cartoon/demo outputs.

## Gate 3 — Compare and export
Link original and derivative; before/after slider; zoom; save/download; image metadata and version lineage.

## Gate 4 — Skill runtime
Skill manifest/registry, discovery, execution contract, isolation, test harness, status and evidence. First integrate the proven skill only.

## Gate 5 — Assistant/task mini-runtime
Task intake, clarification when needed, plan, permission preflight, dispatch, validate, evidence, approval, audit. Persistence and recovery tested before claims.

## Gate 6 — Remaining user apps
Ad Studio, Dealer Workspace and personal assistant capabilities, each tested independently and progressively connected.

## Gate 7 — Admin Browser
REA intake and sandbox, agents, tasks, workflow monitoring, marketing calendar, map research and asset generation. External publishing/actions remain approval-gated.

## Gate 8 — Contextual browser layer
Browser extension/companion with scoped permissions, user-triggered contextual actions and explicit host compatibility tests. Add connectors incrementally; no universal site automation promises.

## Gate 9 — Release verification
Clean install, builds, tests, lint, security review, real-device QA, licence review, docs, archive and exact verification report.
