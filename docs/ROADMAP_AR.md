# خارطة طريق مشكور

آخر تحديث: 27 نوفمبر 2026. الأولوية الآن تثبيت تجربة Photo Studio وجودتها قبل توسيع النطاق.

## المرحلة الحالية — رفع جودة النسخة الأولى

### P0: تجربة الاستخدام
- [ ] حذف الشعار والاسم من الترويسة العلوية في جميع اللغات والاتجاهات.
- [ ] إعادة تصميم ترتيب الجوال وفق مسار المهمة.
- [ ] تحسين بطاقة النتيجة وترتيب أوامر المعالجة والاعتماد والتنزيل.
- [ ] معالجة الفراغات غير المقصودة في تخطيط سطح المكتب.
- [ ] اختصار النصوص والشروحات وتوحيد المصطلحات.
- [ ] فحص عروض 320–430px وRTL/LTR دون قص أو تداخل.

### P1: العرض البصري
- [ ] توفير صور سيارات مرخصة ومتنوعة.
- [ ] إنتاج حالات قبل/بعد حقيقية من المحرك.
- [ ] إنتاج GIF أو فيديو قصير يشرح سير العمل.
- [ ] تحسين قائمة الأعمال والمتخصصين والتفضيلات على الجوال.
- [ ] تحسين حالات الفراغ والتحميل والخطأ والنجاح.

### P2: جودة محرك الصور
- [ ] إنشاء مجموعة اختبار مرجعية لصور سيارات متنوعة.
- [ ] قياس جودة الحواف والتسرب وفقد أجزاء المركبة.
- [ ] قياس زمن المعالجة والذاكرة على أجهزة فعلية.
- [ ] مراجعة تراخيص مكتبة المعالجة وأوزان النماذج والأصول.
- [ ] وضع معيار قبول معلن قبل وصف النتائج بأنها احترافية.

### P3: اختبار وإطلاق
- [ ] اختبار Android Chrome وiOS Safari وأجهزة سطح المكتب.
- [ ] اختبار الإتاحة ولوحة المفاتيح والتباين وتقليل الحركة.
- [ ] توثيق نتائج اختبار الاستخدام والجودة.
- [ ] تقييم الحاجة إلى backend دائم منفصل عن GitHub Pages.

## مبادئ لا تتغير

- لا يُستبدل الأصل.
- لا تُعرض نتيجة أو حالة نجاح وهمية.
- لا تُعلن تكاملات أو نماذج مدربة دون دليل.
- لا يبدأ توسيع المنتج قبل إغلاق مشكلات التجربة الأساسية.
- راجع [وثيقة مراجعة النسخة الأولى](PRODUCT_REVIEW_AND_DOCUMENTATION_UPDATE_AR.md) لمعايير القبول التفصيلية.
