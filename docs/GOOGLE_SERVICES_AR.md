# خدمات Google الاختيارية — مستقلة عن AI Studio

Google AI Studio غير مستخدم في تصميم مشكور أو بناء الواجهة أو تشغيل الخادم.

## تسجيل المستخدمين

المسار الأساسي الحالي هو تسجيل محلي بالبريد وكلمة المرور مع scrypt وSQLite وجلسة HttpOnly؛ لا يحتاج Google Cloud أو API key أو خدمة مدفوعة.

يمكن إضافة Google Sign-In كموصل OIDC اختياري عبر Google Identity Services أو Firebase Authentication. يتطلب ذلك إعداد OAuth Client ID، ونطاقات redirect معتمدة، وسياسة خصوصية ونطاقاً موثقاً. لا نضع Client Secret في الواجهة ولا نستخدم WebView مضمناً لتدفق OAuth.

Firebase Auth يعلن عن خطة Spark دون تكلفة وحدود لبعض الخدمات، لكن الحدود تختلف حسب المنتج وطريقة الدخول، وIdentity Platform له تسعير وحدود مختلفة. نراجع الجدول الرسمي قبل تفعيل أي ترقية. لا نفعل Phone Auth افتراضياً لأنه يعتمد على رسائل SMS مدفوعة.

## الخرائط

في المرحلة الحالية نستخدم روابط عميقة لفتح الموقع في Google Maps دون Maps JavaScript API key، مثال:
https://www.google.com/maps/search/?api=1&query=LAT,LNG

للخريطة داخل صفحة المعرض يمكن استخدام Leaflet + OpenStreetMap مع مزود tiles ملتزم بشروط الاستخدام أو خادم tiles مستضاف ذاتياً عند نمو الاستخدام. لا نستخدم خوادم tiles العامة كخدمة مجانية غير محدودة ولا نكشط Google Maps.

## الحالة

- تسجيل البريد وكلمة المرور: منفذ في المحرك الحالي، يحتاج اختبار بيئة الاستضافة قبل الإنتاج.
- Google OAuth: غير موصل حتى الآن؛ التسجيل المحلي يعمل بدونه.
- رابط Google Maps: مفعّل في بطاقة السيارة من قيمة المدينة/العنوان، عبر deep link دون API key أو رسوم Maps API.
- خريطة Leaflet/OSM مدمجة: مؤجلة حتى تجهيز صفحة المعرض والموقع.
