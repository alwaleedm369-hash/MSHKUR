# الحالة التجارية والهندسية — مشكور

**آخر تحديث:** 27 نوفمبر 2026  
**الحالة:** نموذج أولي منشور للمعاينة؛ غير معتمد بعد كمنتج تجاري نهائي.

## ما تم التحقق منه في نسخة المعاينة

- واجهة React + TypeScript + Vite منشورة على GitHub Pages.
- إزالة خلفية محلية في المتصفح عبر `@bg0/browser` كاعتماد طرف ثالث.
- مقارنة قبل/بعد وتنزيل ناتج المعالجة وفق مسار الواجهة.
- حفظ محلي في المتصفح حيث تدعم البيئة ذلك.
- دعم العربية والإنجليزية واتجاهي RTL/LTR.
- GitHub Actions أكد نجاح CI والنشر على commit `9b9023537b9c60073fd0a79b366a2e4cc30f6bf3`.
- سجل التحقق لهذه النسخة يذكر 87 اختباراً ناجحاً، مع نجاح TypeScript وVite production build.

## ما لم يُعتمد بعد

- جودة قص احترافية على مجموعة سيارات متنوعة وأجهزة فعلية.
- مراجعة بصرية تفاعلية كاملة على iOS Safari وAndroid Chrome.
- تصميم الجوال النهائي وإعادة توزيع مساحة سطح المكتب.
- صور توضيحية/GIF/فيديو تعريفي فعلي للوظيفة.
- حسم جميع تراخيص أوزان النماذج والأصول قبل الاستخدام التجاري.
- اختبارات وصول وأداء وخصوصية على أجهزة حقيقية.

## تكاملات لا نعلن اتصالها

- لا تكامل Higgsfield أو Blender.
- لا تدريب داخلي مثبت لنموذج إزالة خلفية أو نموذج LLM.
- لا WhatsApp API أو ربط QR أو إرسال آلي في هذه المعاينة.
- لا Google OAuth أو Drive متصل.
- لا نشر آلي إلى حراج أو منصات اجتماعية.

## حدود GitHub Pages

GitHub Pages استضافة ملفات ثابتة للواجهة. لا تشغّل Express أو SQLite أو ملفات المستخدمين الخلفية. نجاح النشر لا يثبت تشغيل خدمات backend ولا يكفي لاعتماد المنتج تجارياً.

## قرار الإطلاق

قبل الإطلاق التجاري يجب:
1. إغلاق ملاحظات النسخة الأولى في [خطة رفع الجودة](PRODUCT_REVIEW_AND_DOCUMENTATION_UPDATE_AR.md).
2. اعتماد تصميم الجوال وإزالة الاسم والشعار من الترويسة.
3. اجتياز اختبار صور مرجعي وجودة معالجة موثق.
4. اختبار متصفحات وأجهزة فعلية، RTL/LTR، الإتاحة والأداء.
5. حسم التراخيص والخصوصية والاحتفاظ بالصور.
6. نشر backend منفصل عند الحاجة مع تخزين دائم ونسخ احتياطي واستعادة مختبرة.
