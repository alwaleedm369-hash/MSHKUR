# الحالة التجارية والهندسية — مشكور

**آخر تدقيق:** 23 نوفمبر 2026  
**الحالة:** نواة فعلية قيد التطوير — غير جاهز للإطلاق التجاري.

## ما يوجد فعلياً في main

- React + TypeScript + Vite، وخادم Express، وقاعدة SQLite.
- تسجيل محلي بالبريد وكلمة المرور وعزل مساحات المعارض.
- إدارة سجلات السيارات وبعض وظائف المخزون.
- إزالة خلفية محلية في المتصفح عبر BG0/BiRefNet.
- تحسين صور محلي، طمس منطقة لوحة يحددها المستخدم، ومكونات منفصلة للمشهد والزجاج والقص.
- مسودة إعلان من بيانات السيارة المؤكدة.
- Maestro/Skills/Workflows ومركز مهام وسجل موافقات.
- صفحة معرض عامة، محادثة موقع تحفظ الاستفسارات، وInbox للمالك.
- روابط WhatsApp click-to-chat وروابط خرائط Google.

## ما لا نعلن أنه متصل

- لا كشف تلقائي للوحات أو الزجاج.
- لا بوت WhatsApp داخل صندوق الوارد، ولا ربط QR لجلسة شخصية أو إرسال آلي.
- لا Google OAuth أو Drive أو خريطة Maps API مدمجة.
- لا نموذج LLM افتراضي للمساعد؛ النموذج المحلي اختياري، والواجهة العائمة غير موصولة حالياً بمسار الرد.
- لا نشر تلقائي إلى حراج أو منصات التواصل.
- لا رادار سيارات/تمويل أو مطابقة تمويل متعددة الجهات.
- استوديو الزائر وسير إنشاء الإعلان لا يشكلان بعد مساحة مشروع سيارة موحدة ومستمرة من البداية إلى النهاية.

## المعاينة

تم إعداد Vite build لمسار GitHub Pages وإضافة workflow خاص للنشر. يلزم تغيير Settings → Pages → Source إلى GitHub Actions. تشغيلات Actions الحديثة تتوقف عند `startup_failure` قبل إنشاء أي Jobs؛ لذلك لا يوجد build/test ناجح يثبت المعاينة الجديدة حتى الآن.

GitHub Pages للواجهة الثابتة فقط، ولا يشغل Express أو SQLite أو ملفات المستخدمين. يلزم نشر backend على بيئة Node.js مع قرص دائم.

## قرار الإطلاق

لا يوصف مشكور بأنه منتج جاهز حتى:
1. يبدأ Actions runner وتنجح اختبارات `npm test` و`npm run build`.
2. توحّد شاشة البداية ومساحة المشروع على تجربة الأداة أولاً والجوال أولاً.
3. تتصل نتائج الصور بملف السيارة والحفظ الدائم والتنزيل/المشاركة/الإعلان.
4. يُوصل المساعد بالمهارات الفعلية أو يعرض بوضوح أن النموذج غير مهيأ.
5. تنجح اختبارات Android وiOS، جودة الصور، tenant isolation، النسخ الاحتياطي، والخصوصية.
