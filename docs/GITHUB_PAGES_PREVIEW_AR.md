# معاينة GitHub Pages — مشكور

## إعداد النشر

1. افتح المستودع ثم Settings → Pages.
2. في Build and deployment اجعل Source = GitHub Actions.
3. شغّل workflow باسم "Deploy MSHKUR preview to GitHub Pages" من تبويب Actions، أو ادفع تحديثاً إلى main.
4. افتح رابط Pages بعد اكتمال build وdeploy.

يبني workflow التطبيق باستخدام Node.js 22 وVite، ثم يرفع مجلد dist. يستخدم إعداد Vite المسار /MSHKUR/ عند البناء في GitHub Actions، ويضيف 404.html كمسار احتياطي لتطبيق React أحادي الصفحة.

## حدود هذه المعاينة

GitHub Pages استضافة ملفات ثابتة فقط. هذه المعاينة تعرض واجهة React ومزايا المتصفح التي لا تحتاج خادماً، لكنها **لا تشغّل** Express API أو SQLite أو تخزين ملفات المستخدمين. لذلك لا تعتبر تسجيل الحسابات وحفظ السيارات والمهام والوارد ومركز الإدارة متصلة في Pages.

لتشغيل مشكور كاملاً، انشر خدمة Node.js من المشروع نفسه على استضافة تدعم:
- Node.js 22 أو أحدث.
- تشغيل Express عبر `npm start`.
- قرصاً دائماً لمساري `MSHKUR_DB_PATH` و`MSHKUR_STORAGE_DIR`.
- HTTPS ونسخاً احتياطياً مجرّباً.

لا تضع أسرار OAuth أو مفاتيح Google أو أسراراً أخرى في Vite أو في متغيرات `VITE_*`؛ يجب أن تبقى أسرار الخادم في إعدادات الاستضافة.

## التحقق

نجاح بناء صفحات GitHub يثبت بناء حزمة الواجهة فقط. لا يثبت تشغيل API أو اختبارات الإنتاج أو تدفق التسجيل والحفظ؛ يجب اجتياز اختبارات المستودع وتجربة الخدمة المنشورة منفصلة.
