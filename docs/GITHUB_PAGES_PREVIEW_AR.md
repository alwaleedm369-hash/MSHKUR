## حالة النشر

اكتمل GitHub Actions build ورفع artifact ونشر Pages بنجاح. سجل النشر أظهر `Reported success!` ورابط البيئة أعلاه. كما نجح مسار التحقق المرتبط بهذه النسخة، وسجل 87 اختباراً ناجحاً.

## حدود المعاينة

GitHub Pages يستضيف ملفات الواجهة الثابتة فقط. لا يشغّل Express API أو SQLite أو تخزين الملفات الخلفي. لذلك لا تعتبر المعاينة دليلاً على اتصال وظائف الخادم أو تسجيل الحسابات أو المزامنة السحابية.

## ما يجب اختباره يدوياً

- افتح الموقع على Android Chrome وiOS Safari وسطح المكتب.
- جرّب رفع صورة فعلية وإزالة الخلفية ومقارنة النتيجة وتنزيلها.
- اختبر الصور الكبيرة، حالات الفشل، إعادة التحميل، التخزين المحلي.
- اختبر العربية RTL والإنجليزية LTR وأحجام الشاشات.
- راجع [مراجعة النسخة الأولى وخطة رفع الجودة](PRODUCT_REVIEW_AND_DOCUMENTATION_UPDATE_AR.md).

لم يتم توثيق اختبار بصري تفاعلي على أجهزة فعلية ضمن تحقق النشر المذكور؛ لا تدّعِ ذلك حتى ينفذ ويسجل.

## التطوير

```bash
npm test
npm run typecheck
npm run build
```

## حماية الأسرار

لا تضع أسرار OAuth أو مفاتيح خاصة في Vite أو متغيرات `VITE_*`. تبقى أسرار الخدمات في إعدادات backend والاستضافة.
