# فحص تراخيص المكتبات والأوزان

لا يتم استيراد مشروع لمجرد أنه مشهور أو مفتوح المصدر. لكل مكون نسجل: مستودع المصدر، الإصدار المثبت، ترخيص الشيفرة، ترخيص الأوزان/الأصول، الاعتماديات العابرة، التزامات SaaS والتوزيع، حالة الصيانة والثغرات.

## تحذيرات

- BG0 يضمّن مسار HEIC/HEIF يعتمد على heic-to وlibheif وlibde265 بتراخيص LGPL-3.0-or-later. واجهة مشكور تقبل PNG/JPEG/WebP فقط حالياً، لكن يجب الاحتفاظ بالإشعارات ومصادر المكونات المطابقة المرفقة مع BG0.
- النموذج Lite يقارب 98.5 MB، والنموذج Full يقارب 473.4 MB؛ لا نحمّل النموذج مع أول فتح للتطبيق، بل عند اختيار المهمة.
- لا ندمج FFmpeg WASM قبل حسم تراخيص core؛ غلاف npm لا يحدد ترخيص ملفات WASM.
- لا نضمّن نماذج Qwen أو غيرها قبل مراجعة ترخيص checkpoint وONNX export وملفات التوزيع.
- REA (morluto/rea) MIT أداة تطوير MCP فقط، ولا تُضمّن في خادم الإنتاج.
- لا نعتمد أدوات skills-ref كاعتماد runtime؛ يمكن استعمال validator في CI فقط بعد مراجعة ملاءمته.

هذه القائمة أولية ويجب تحديثها قبل إصدار تجاري، مع حفظ THIRD_PARTY_NOTICES لكل إصدار.
