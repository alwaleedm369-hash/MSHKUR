# REA وMCP في مشكور

## REA — Reasoning, Extraction, Automation

هذا هو التوسيع الوارد في تقرير المشروع:
- Reasoning: فهم النية واختيار مسار العمل.
- Extraction: استخراج الحقول وتحويلها إلى بيانات منظمة والتحقق منها.
- Automation: تشغيل المهارة المسموحة وتنفيذ الخطوات.

بدأ التنفيذ بمصنف نوايا حتمي باللغة العربية، ومخططات Zod، وسجل مهارات allowlist. لم نربط نموذجاً مدفوعاً ولم نسمح للنموذج بتوليد شيفرة قابلة للتنفيذ.

## MCP — Model Context Protocol

الاختصار الوارد في المرفق هو MCP، وليس CMP. MCP طبقة اتصال اختيارية لأدوات وخوادم خارجية. لا نفتح MCP listener عاماً في النسخة الأولى؛ سنضيف registry/adapter بعد تحديد المصادقة والصلاحيات ومصدر الخادم وحدود الأدوات. كل أداة مستوردة تمر بمراجعة ترخيص وأمن، وتعمل في allowlist. لا يسمح لأي خادم MCP بتنفيذ shell أو كتابة ملفات عامة أو الوصول إلى أسرار المعرض دون عزل وموافقة.

## REA لا تعني استنساخ الشيفرة

ندرس سلوك المنتج والرحلات والواجهات والميزات العامة، ثم نعيد تنفيذ الوظيفة بشكل مستقل. لا نسحب شيفرة مغلقة ولا نتجاوز المصادقة أو CAPTCHA أو شروط الخدمة.
