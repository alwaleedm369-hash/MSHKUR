# الواجهة الرئيسية + استوديو الجوال — MSHKUR
## مستوحاة من Spyne.ai و CarFlow.ai مع لمسات مشكور

تاريخ: 2026-11-18  
الهدف: واجهة يعمل المستخدم عليها فوراً، والشروحات في الأسفل.

---

## المبادئ التصميمية (مستخلصة من Spyne + CarFlow)

1. **الأداة أولاً**: المستخدم يدخل ويرى معاينة قبل/بعد كبيرة + زر ابدأ.
2. **خلفية بيضاء نظيفة** للاستوديو.
3. **صور الأصول الأصلية** تظهر في صف مصغّر أفقي (thumbnails).
4. **قائمة قوالب الخلفيات** (مثل Spyne): بطاقات صغيرة قابلة للاختيار داخل لوحة جانبية أو أسفل.
5. **Contact Shadows**: ظل واقعي تحت الإطارات حتى لا تبدو السيارة «طائرة».
6. **قبل/بعد بمقبض سحب** واضح وكبير.
7. **الكلام والشروحات** تنزل للأسفل بعد منطقة العمل (مثل المواقع العالمية).
8. **زر ابدأ** بارز في الأعلى.

## هيكل الشاشة الرئيسية للجوال (Guest + Logged)

### المنطقة العلوية (Working Zone — لا تزدحم بالنصوص)

```
[شعار مشكور]                    [قائمة]

┌─────────────────────────────────────┐
│  معاينة كبيرة قبل / بعد             │
│  (مقبض سحب في المنتصف)              │
│  صورة سيارة حقيقية                  │
└─────────────────────────────────────┘

[صف مصغّرات الصور الأصلية]  ←→  قابلة للتمرير أفقياً

[زر كبير: ابدأ التجهيز الآن]
```

### منطقة قوالب الخلفيات (مثل Spyne)

```
قوالب الاستوديو
[أبيض] [رمادي] [داكن] [معرض] [رخام] [خارجي] ...
← بطاقات مصغّرة قابلة للاختيار
```

### شريط الأدوات السفلي داخل الاستوديو

- إزالة خلفية
- طمس لوحة
- قص
- استوديو مشاهد
- تظليل زجاج

### المنطقة السفلية (Scroll للأسفل — الشروحات)

- كيف يعمل مشكور (3 خطوات بسيطة)
- أمثلة قبل/بعد إضافية
- لماذا المعارض تستخدمه
- حدود الاستخدام المجاني
- روابط التسعير / التسجيل

## بطاقة النشر الموحدة (Unified Bottom Sheet)

عند انتهاء المعالجة تظهر بطاقة من الأسفل:

```
تم تجهيز السيارة
[معاينة سريعة]

انشر على:
[حراج] [مستعمل] [𝕏] [واتساب]

[✔️ راجع ووافق على النشر]
```

- لا نشر تلقائي.
- النص جاهز للنسخ أو فتح `wa.me`.
- الموافقة البشرية إلزامية.

## تفاصيل تقنية للتنفيذ

### المكونات المقترحة (React)

- `GuestLanding.tsx` — الصفحة الرئيسية للزائر (معاينة + أدوات + شروحات بالأسفل)
- `CarProjectStudio.tsx` — الاستوديو داخل مشروع السيارة
- `BackgroundTemplatePicker.tsx` — قائمة قوالب الخلفيات (أبيض افتراضي)
- `BeforeAfterSlider.tsx` — مقبض السحب
- `OriginalThumbsRow.tsx` — صف المصغّرات
- `PublishBottomSheet.tsx` — بطاقة النشر + موافقة
- `ContactShadowLayer.tsx` — طبقة ظل تحت السيارة (Canvas أو CSS + صورة ظل)

### قواعد الخلفية البيضاء

- الافتراضي عند إزالة الخلفية = خلفية بيضاء نظيفة + ظل تماس.
- القوالب الأخرى اختيارية من القائمة.
- لا توليد أجزاء جديدة من السيارة.

### OCR (لاحقاً)

- أيقونة كاميرا بجانب حقول السيارة.
- التقاط صورة الاستمارة → استخراج الماركة/الموديل/السنة/الهيكل (بعد اختيار محرك OCR مرخص محلي أو اختياري).

### 360 / Story Mode (لاحقاً)

- تجميع الصور المرتبة في عارض بسيط (سوايبر).
- QR يوجه إلى صفحة السيارة العامة.

## ما يبقى محلياً وبدون API مدفوع

- إزالة الخلفية: BG0 / BiRefNet في المتصفح (موجود).
- الظل التركيبي: Canvas محلي.
- واتساب: `wa.me` فقط.
- التخزين: محلي + SQLite + ملفات tenant.
- Maestro + موافقات بشرية.

Google Drive / Sheets تبقى موصلات اختيارية لاحقة كما في الوثائق الحالية.
