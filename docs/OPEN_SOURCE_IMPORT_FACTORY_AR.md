# مصنع استيراد المشاريع والمهارات — MSHKUR

## الهدف

استفادة MSHKUR من المشاريع المفتوحة المصدر دون نسخ تطبيق كامل أو إدخال تبعيات لا تتوافق مع React + Express + SQLite أو شروط الترخيص التجاري.

## قاعدة الاستيراد

1. تسجيل المصدر: رابط المستودع، commit محدد، الترخيص، تاريخ المراجعة.
2. استنساخ المصدر إلى مساحة مراجعة منفصلة، وليس إلى مجلد التشغيل.
3. قراءة LICENSE وREADME وملفات الاعتماديات وملفات SKILL.md.
4. فصل كود المشروع عن أوزان النماذج والبيانات والعينات؛ لكل منها ترخيص مستقل.
5. استخراج المهارة/الخوارزمية المطلوبة فقط، ثم إعادة تنفيذها كوحدة صغيرة متوافقة مع MSHKUR.
6. فحص الصلاحيات والمدخلات والمخرجات، ثم اختبارات واختبار عزل tenant.
7. إبقاء الاستيراد في حالة review_required حتى اعتماد المالك. لا يتم تنفيذ كود مستورد تلقائياً.
8. تثبيت upstream commit وملف NOTICE، وتوثيق التعديلات المحلية لتسهيل تحديث المصدر لاحقاً.

## ما يجب عدم استيراده مباشرة

- تطبيقات كاملة تستخدم قواعد بيانات أو أنظمة صلاحيات مختلفة دون خطة ترحيل.
- أي مستودع بلا LICENSE واضح.
- أوزان نماذج لا يصرح ترخيصها بالاستخدام التجاري.
- سكربتات shell أو browser automation أو MCP tools ذات صلاحيات واسعة.
- أي كود يرسل صور العملاء أو بياناتهم إلى طرف ثالث دون موافقة واضحة.

## مراحل تنفيذ المستورد

### المرحلة A — مصدر ومراجعة
تخزين metadata وcommit وlicense وملفات المصدر المقروءة، وإظهار تقرير الفحص.

### المرحلة B — استخراج المهارة
تحويل الإجراء إلى Skill Manifest: المدخلات، المخرجات، runtime، الصلاحيات، حدود الموارد، المخاطر، الاختبارات.

### المرحلة C — محول آمن
تنفيذ المهارة كـbuiltin داخل MSHKUR أو WASM/worker معزول. يمنع تنفيذ shell أو كود Node المستورد في عملية الخادم.

### المرحلة D — تجربة واعتماد
تشغيل اختبارات fixtures محلية، عرض before/after، مراجعة النتائج، ثم موافقة المالك على تفعيل المهارة.

### المرحلة E — تحديث المصدر
تثبيت commit المصدر، مقارنة upstream diff، وإعادة المراجعة قبل كل تحديث.

## الحالة الحالية

- واجهة مكتبة المهارات وسير العمل وسجل المهام أضيفت.
- API الحالي يعرض المهارات والمهام وسير العمل المسجل.
- استيراد GitHub الحي، استنساخ المستودع إلى منطقة حجر، فحص الترخيص آلياً، وتفعيل المهارة المستوردة **لم تُنفذ بعد**.
- لا يوجد تنفيذ لكود upstream داخل التطبيق.
