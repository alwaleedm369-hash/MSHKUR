# Skills, Agents, Workflow
Skills are operational units with schema, tool binding, permissions, error policy, version and tests—not instruction-only files.
Skills: intake, cutout, matte, plate privacy, lighting, glass tint, scene composition, quality review, ad prep (later).
Agents: Intake (validate/propose); Pipeline (run registered tools); Quality (review warnings); Listing (later, editable factual drafts); Coordinator (task DAG).
Boundaries: no arbitrary filesystem/network access, no publish/delete/transfer without explicit approval.
Workflow: upload -> normalize -> plate privacy -> cutout -> refine -> light/color -> glass -> scene/shadow -> QA -> export -> user review.
