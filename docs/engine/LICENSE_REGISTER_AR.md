# Model and license register
No model/weight is automatically approved by repository license alone. Check code, checkpoint, dataset, dependencies and redistribution terms separately; save license snapshot, hash, source and date.
| Candidate | Use | Gate |
| BiRefNet family | car foreground | confirm exact checkpoint/release license and benchmark |
| SAM 2 | mask correction | official repo reports Apache 2.0 for model/code/checkpoints; review third-party dependencies |
| OpenCV 4.5+ | classic image processing | official page reports Apache 2.0 for 4.5+ |
| ONNX Runtime / Sharp | inference and image transforms | review installed versions/dependencies |
| Plate detector | plate localization | shortlist and weights-license audit; benchmark region-specific plates |
Sources: https://github.com/ZhengPeng7/BiRefNet ; https://github.com/facebookresearch/sam2 ; https://opencv.org/license/
