E1: segmentation adapter, model cache/hash, mask editor, edge QA, export, benchmark.
E2: plate detector shortlist, dataset, manual region, privacy modes, output validation.
E3: light/color sliders, reversible recipes, clipping guard.
E4: glass manual mask, tint blend, edge/reflection tests.
E5: scene compositor, licensed backgrounds, shadows and quality checks.
E6: tool registry, DAG state/retry/cancel, bounded agents.
E7: device/browser tests, privacy, retention, accessibility, license/SBOM, rollback.
Definition of Done: actual user image processed; tested failure states; valid output; compare; build/smoke; recorded provenance; documented privacy.
