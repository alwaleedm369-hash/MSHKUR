# محرك مشكور الداخلي — المرحلة الثانية

## REA كما ورد في مرجع المشروع

- **Reasoning:** فهم الطلب وتحديد المهارة والخطوات.
- **Extraction:** استخراج المدخلات والحقول المنظمة والتحقق منها.
- **Automation:** تشغيل المهارات وسير العمل وإرجاع النتيجة.

لا يعني REA تجاوز صلاحيات المواقع أو استنساخ شيفرة خاصة. نعيد تنفيذ السلوكيات المفيدة بصورة مستقلة باستخدام مكتبات مرخصة أو تكاملات مصرح بها.

## ما أصبح موجوداً في الكود

- SQLite محلي دائم مع WAL ومفاتيح أجنبية.
- عزل بيانات المستخدمين حسب tenant_id في مسارات السيارات والمهام.
- تسجيل بريد/كلمة مرور محلي مع scrypt وجلسة عشوائية مخزنة كـ SHA-256 hash في قاعدة البيانات وCookie HttpOnly.
- مهارات مسجلة في allowlist، لا يمكن للنموذج اختراع handler وتنفيذه.
- Maestro أولي ينشئ job ويشغله ويسجل نجاحه/فشله، ويعيد المهام queued بعد إعادة تشغيل الخادم.
- أدوات محلية حقيقية: تجهيز مسودة إعلان من حقائق المستخدم، تدقيق سجل السيارة، تحويل الصور إلى WebP، وتمويه منطقة مستطيلة يحددها المستخدم.
- سجل تدقيق للإنشاء والدخول والمهام والسيارات.

## حدود المرحلة الحالية

هذا ليس بعدُ محرك وكلاء لغوياً ولا موزع مهام متعدد العمال. التصنيف الحالي يعتمد skillId المرسل من الواجهة، والتنفيذ محلي ومحدود بأربع مهارات. لا يوجد Google OAuth أو WhatsApp أو MCP Server أو رفع ملفات دائم أو فريق موظفين متعدد الصلاحيات أو موافقات خارجية مفعلة بعد.

## قرار قاعدة البيانات

استخدمنا SQLite محلياً لتجنب رسوم قاعدة بيانات خارجية في أول نسخة، وهو مناسب لبداية منخفضة الحركة على خادم Node واحد مع قرص دائم. لا يناسب مشاركة ملف DB على عدة خوادم أو كثافة كتابة عالية. عند التوسع ننقل إلى PostgreSQL مع ترحيل موثق. يجب أن يشير MSHKUR_DB_PATH إلى قرص دائم على Hostinger؛ لا تستخدم مجلد نشر مؤقت.

## نموذج التشغيل

1. API يتحقق من جلسة المستخدم.
2. يتحقق من tenantId من الجلسة لا من جسم الطلب.
3. يتحقق من skillId في allowlist ومن شكل input.
4. ينشئ job في SQLite.
5. يشغل handler محلياً.
6. يحفظ الناتج والخطأ وسجل التدقيق.
7. يعرض الناتج للمستخدم للمراجعة.

## سياسة الإجراءات

المهارات المحلية التي تعالج ملفاً قدمه المستخدم يمكنها التنفيذ مباشرة وإظهار معاينة. أي إرسال/نشر/شراء/حذف/تغيير خارجي يحتاج موافقة مستقلة مرتبطة بمحتوى الإجراء والوجهة.
