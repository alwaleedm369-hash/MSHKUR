# الجوال وواتساب — نطاق التنفيذ الحالي

## ما أضيف في هذا الفرع

- زر تصوير مباشر من كاميرا الهاتف الخلفية عبر `capture="environment"`، مع بقاء اختيار الصور المتعددة متاحاً.
- مشاركة ملفات النتائج عبر Web Share API عندما يسمح المتصفح بمشاركة الملفات.
- رابط `wa.me` لفتح محادثة أو اختيار جهة اتصال مع نص عربي جاهز.
- التحقق من رقم دولي بين 8 و15 رقماً، والتحقق من أن رابط القناة يعود إلى نطاق WhatsApp الرسمي.
- اختبارات Node مستقلة لدوال روابط واتساب.

## ما لا ندعي أنه يعمل

- لا توجد أتمتة غير رسمية لواتساب ويب، ولا قراءة QR لجلسة شخصية، ولا scraping أو إرسال آلي.
- لا يمكن نشر منشور إلى قناة واتساب برمجياً من رابط القناة وحده. المسار الآمن دون Meta API هو تجهيز النص والصورة، ثم يراجع المستخدم المحتوى ويرفعه بنفسه إلى القناة.
- مشاركة الملف عبر Web Share API تعتمد على دعم المتصفح ونظام التشغيل؛ عند عدم توفره يجب تنزيل الصورة وإرفاقها يدوياً.
- لا يوجد حتى الآن ربط Google Drive أو مزامنة تلقائية.
- لم يثبت بعد أن حجم PWA المثبت أقل من 2MB. نموذج إزالة الخلفية Lite منفصل عن غلاف التطبيق ويقارب 98.5MB، ويتم تنزيله عند أول استخدام؛ لذلك لا يصح إدخاله ضمن وعد حجم التطبيق الصغير.
- إزالة الخلفية الحالية محلية عبر BG0/BiRefNet، ولا تعتمد على API مدفوع، لكنها تستهلك ذاكرة ومعالجة الجهاز وقد تكون بطيئة على الهواتف الضعيفة.

## اختبارات هذا الفرع

- اختبارات دوال روابط واتساب: 5 اختبارات ناجحة في تشغيل Node معزول.
- GitHub Actions: لا تزال تشغيلات `verify` و`package-source` تنتهي بـ `startup_failure` قبل إنشاء أي Jobs؛ لذلك لم يثبت بعد نجاح اختبارات المستودع الكامل أو TypeScript أو الإنتاج.
- يجب تنفيذ اختبار حقيقي على Android وiOS: الكاميرا، اختيار عدة صور، نموذج BG0، مقارنة قبل/بعد، التنزيل، والمشاركة.

## بوابة قبول الجوال

1. قياس حجم ملفات غلاف PWA الناتجة عن build دون أوزان النموذج.
2. اختبار التثبيت والتحديث والعمل بعد فقد الاتصال.
3. قياس RAM وزمن المعالجة على أجهزة متوسطة ومنخفضة.
4. توفير مسار معالجة احتياطي للأجهزة التي لا تتحمل النموذج المحلي، دون تحويله إلى API مدفوع إلزامي.
5. عدم تصغير الصورة الأصلية قبل segmentation بشكل يضر تفاصيل السيارة؛ ضغط الرفع يطبق فقط على مسارات الرفع الشبكي وبإعدادات قابلة للضبط.
6. اختبار Web Share API ومشاركة الملف فعلياً إلى WhatsApp على أجهزة مدعومة، مع مسار تنزيل يدوي احتياطي.
