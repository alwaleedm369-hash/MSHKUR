# Vehicle Ad Copy

1. Use only values explicitly provided by the user or stored in the authorized vehicle record.
2. Never invent trim, options, condition, accident history, ownership, warranty, inspection, or service history.
3. Leave unknown facts out; do not fill them from model knowledge.
4. Produce a concise title and structured Arabic description.
5. Mark the result as a draft and require owner review before publishing.
