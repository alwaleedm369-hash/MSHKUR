- الاسم:
- النوع: repository / library / model / demo / product / paper / UI reference

- رابط الوثائق:
- GitHub owner/repo:
- default branch:
- commit SHA / release:
- تاريخ الفحص:
- حالة الوصول:

## الوظيفة المحددة

- المدخلات:

- القيود:

- صورة رسمية + رابط المصدر:
- Demo مباشر:

- لقطة MSHKUR:

- output fixture ID:

- حقوق الصورة/الفيديو:
- ماذا تثبت الصورة؟:

## قرار الدمج
- status: research / prototype / approved / hold / rejected / deprecated
- القرار وسببه:
- skill ID:

- tests:
- reviewer:

- ملاحظات التحديث:
